# 診断コード表

CDL の診断コードの一覧。帯の割り当ては SPEC.md 第 10 章に従う。

- コードの意味は変えない。意味を変えたいときは、新しいコードを振る。
- この表は `crates/cdl-diag/src/code.rs` の定義と一致させる（テストで検査する）。
- 「意味」の欄は、コードが表す誤りの種類を短く書く。利用者に見せるメッセージは、診断ごとに別に作る。

| コード | 意味 | 導入 edition |
| --- | --- | --- |
| E0001 | 閉じていない文字列 | 1 |
| E0002 | 不正なエスケープ | 1 |
| E0003 | 閉じていないテンプレート文字列 | 1 |
| E0004 | 閉じていないブロックコメント | 1 |
| E0005 | 使えない形のリテラル（`0o`・先頭 0 の数値・BigInt・正規表現） | 1 |
| E0006 | 有限にならない数値リテラル | 1 |
